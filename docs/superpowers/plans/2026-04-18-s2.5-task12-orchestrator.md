## 3. Batch-mode orchestration (the scope compromise)

Codex's ideal (iteration-level interleaving) requires refactoring `Separator::separate` to expose a resumable `step()`. That's a 2-3 task scope on its own. For Task 12 we ship **batch mode**, which trades fine-grained interleaving for implementation simplicity while preserving determinism and parity invariants.

### 3.1 Outer loop

```text
pub fn optimize_multi(assignment, request, _cfg) -> FfdAssignment:
    let t0 = Instant::now()
    let global_deadline = t0 + request.time_budget
    let per_bin_quota = request.time_budget / n_bins_initial  # FIXED lifetime cap

    # Single-bin fast path: degenerate to Task 8 optimize() semantics.
    # Do NOT instantiate orch_rng, round counters, or operator scheduling.
    if n_bins_initial == 1:
        return optimize_single_bin(assignment, request, global_deadline)

    let mut cur = assignment
    let mut operator_gap = 1                    # rounds between operator ticks
    let mut rounds_until_next_operator = 0      # counter gated by operator_gap
    let mut consecutive_noop_operator_ticks = 0  # termination counter
    let mut gls_spent_ms: Vec<u64> = vec![0; n_bins]    # lifetime accounting
    let mut orch_rng = Xoshiro::from_seed(request.seed)

    for round in 0..MAX_ROUNDS:
        # Phase A: optimize every bin slot (non-empty optimized; empty
        # still draws its RNG seed to preserve positional determinism).
        cur = optimize_all_bins(cur, request, per_bin_quota,
                                &mut gls_spent_ms, global_deadline,
                                &mut orch_rng)

        if past(global_deadline): return cur

        # Phase B: operator ladder — GATED by operator_gap countdown.
        if rounds_until_next_operator > 0:
            rounds_until_next_operator -= 1
            continue

        let committed = apply_operator_ladder(cur, request, …)

        match committed:
            Some(next) =>
                cur = next
                consecutive_noop_operator_ticks = 0
                operator_gap = 1                 # reset back-off
                rounds_until_next_operator = 0
            None =>
                consecutive_noop_operator_ticks += 1
                if consecutive_noop_operator_ticks >= TERMINATION_NOOP_TICKS:
                    return cur
                operator_gap = min(operator_gap * 2, MAX_GAP)
                rounds_until_next_operator = operator_gap - 1
```

Constants:
- `MAX_GAP = 8` rounds between operator ticks after successive no-ops.
- `TERMINATION_NOOP_TICKS = 3` (consecutive no-op operator *ticks* — not rounds — trigger exit). Codex-locked: gated by `operator_gap`, so this counts real operator invocations only.
- `MAX_ROUNDS = 20` safety cap.

**Why back-off needs `operator_gap` as a real gate (Codex fix):** Running the operator ladder every round burns greedy_bottom_left probes on unchanged assignments. After N no-ops, we skip operator phases for `operator_gap-1` rounds and let Separators keep working on geometry without assignment churn.

### 3.2 `optimize_all_bins` helper (positional RNG + lifetime quota)

```text
fn optimize_all_bins(
    mut assignment,
    request,
    per_bin_quota,
    gls_spent_ms: &mut [u64],
    global_deadline,
    orch_rng,
) -> FfdAssignment:
    for bin_idx in 0..n_bins:
        # Draw seed FOR EVERY BIN SLOT, including empties, so the RNG
        # stream is positionally deterministic. (Codex fix: empties
        # changing downstream seeds would break reproducibility.)
        let bin_seed = orch_rng.next_u64()

        if past(global_deadline): continue   # keep drawing to stay positional
        if assignment.per_bin[bin_idx].placements.is_empty(): continue

        # Remaining lifetime budget for this bin.
        let bin_remaining = per_bin_quota.saturating_sub(gls_spent_ms[bin_idx])
        if bin_remaining == 0: continue

        let slice = min(bin_remaining, (global_deadline - now).as_millis())
        if slice == 0: continue

        let items_for_bin = items_for_seed(&assignment.per_bin[bin_idx], &request.items)
        let bin_config = OptimizerConfig {
            time_budget_ms: slice,
            seed: Some(bin_seed),
            bin: request.bins[bin_idx].clone(),
            items: items_for_bin,
            clearance: request.clearance,
            …
        }

        let t0 = Instant::now()
        let new_seed = search::optimize(assignment.per_bin[bin_idx].clone(), bin_config)?
        let actual_ms = t0.elapsed().as_millis() as u64
        gls_spent_ms[bin_idx] += actual_ms

        assignment.per_bin[bin_idx] = new_seed
    assignment
```

Calls today's `search::optimize` unchanged. Key invariants:
- **Positional RNG:** one `next_u64()` per bin index per round regardless of whether the bin is optimized. Empties consume their seed without using it.
- **Lifetime quota:** `gls_spent_ms[bin_idx]` accumulates across rounds. Each bin has a FIXED lifetime cap of `per_bin_quota` (Codex rule — no re-granting per round).
- **Single-pass through positional loop even past the deadline:** so RNG state finishes the round consistently before the outer loop exits.

### 3.3 `apply_operator_ladder` helper (Codex-fixed: unload outside pair loop)

```text
fn apply_operator_ladder(assignment, request) -> Option<FfdAssignment>:
    # 1. unload is ONE-SHOT per tick (scans all bins internally).
    if let Some(new) = unload_lightest_bin(&assignment, …)?:
        return Some(new)

    # 2. migrate: iterate (a, b) pairs with a != b, a < b.
    for a in 0..n_bins:
        for b in (a+1)..n_bins:
            if let Some(new) = migrate(&assignment, a, b, None, …)?:
                return Some(new)
            # Also try reverse direction (a→b vs b→a).
            if let Some(new) = migrate(&assignment, b, a, None, …)?:
                return Some(new)

    # 3. swap_two: same pair enumeration.
    for a in 0..n_bins:
        for b in (a+1)..n_bins:
            if let Some(new) = swap_two(&assignment, a, b, …)?:
                return Some(new)

    None
```

Codex fix: `unload_lightest_bin` scans all bins internally (§3 of Task 11 cross_bin_swap plan). Placing it inside a `(a, b)` pair loop would invoke it N×(N-1) times with identical results — wasted work. One call per operator tick is correct.

Ladder order matches Codex §6: highest-impact first (closing a bin), then moderate (migration can close source), then lowest (swap redistributes).

## 4. Cached-state invariant (Codex-critical)

**Never round-trip through `snapshot_to_seed` + `state_from_assignment` just to read assignment state.** The authoritative assignment state between commits is the cached `FfdAssignment` returned by `ffd_assign()` or the last operator commit. `SeedPlacements` inside each bin's `SeedResult` only carry geometry; shape counts are implicit via `len()`.

Per Codex: Separator iterations never change per-bin cardinality (`separator.rs:390` guarantees it). So between commits, the assignment state is invariant; we only update `SeedResult.placements` (geometry refinement).

### 4.1 When to call `assignment_from_state` / `state_from_assignment`

- `state_from_assignment(cur)` — inside each operator (already does this internally).
- `assignment_from_state(…)` — inside each operator to return the committed result.

That's it. The orchestrator itself never calls these. It just threads `FfdAssignment` through and replaces it on commit.

## 5. Transactional touched-bin commits (Codex-required)

The current operator implementations already commit transactionally (via shadow state). Task 12's orchestrator just needs to:

1. Accept the returned `FfdAssignment` as the new `cur`.
2. NOT re-optimize bins whose placements didn't change (optimization; not correctness).

**Correctness for batch mode:** every round re-optimizes every non-empty bin. Even untouched bins get re-optimized, which means their Separator state is discarded each round. This is wasteful but safe. Task 12 doesn't preserve per-bin search session state across rounds — that's Task 13+ territory.

**Optimization hook (not in Task 12 scope):** detect which bins' `SeedResult` changed vs pre-operator, skip optimize for unchanged bins. Punt to follow-up.

## 6. Determinism

Three sources of randomness, all deterministic under `request.seed`:

1. **Orchestrator RNG:** `Xoshiro::from_seed(request.seed)`. One draw per bin per round gives that bin's per-round seed.
2. **Per-bin Separator:** seeded from (1)'s draw.
3. **Operators:** pure, no RNG.

Iteration order is strict `0..n_bins` index order. Round counter advances by 1 per full pass.

This matches Gemini's §7 recommendation exactly. Bit-identical outputs under fixed `request.seed`.

## 7. Budget accounting — lifetime quota (Codex-corrected)

```text
global_deadline = started_at + request.resolved_time_budget_ms()
per_bin_quota   = total_budget / n_bins_initial     # FIXED lifetime cap
gls_spent_ms[i] = 0 for all bins initially          # accumulates across rounds
```

For each bin per round:
```text
bin_remaining = per_bin_quota.saturating_sub(gls_spent_ms[i])
slice_ms      = min(bin_remaining, global_deadline - now)
```

Key invariants (Codex sign-off):
- **`per_bin_quota` is a LIFETIME cap**, not a per-round allowance. A bin that burns its quota in round 1 gets zero time in round 2.
- Operator evaluation + `greedy_bottom_left` probe time is charged to the global deadline only — NOT to any `gls_spent_ms[i]`.
- **No quota redistribution** after `unload_lightest_bin` closes a bin. The freed quota is forfeited; this preserves reproducibility (timing-based redistribution would break determinism).
- If global deadline elapses mid-round, the round continues through the positional RNG draws (to preserve determinism) but skips actual `search::optimize` calls.

## 9. Sharp edges / guardrails

All from Codex §10 + sign-off:

1. `Layout` never stores overflow — overflow lives in `FfdAssignment.overflow` only.
2. Rebuild touched bins with the SAME request-order items to preserve `item_id` stability. `materialize_parts` emits sorted-by-shape_id internally, but `items_for_seed` preserves original request order (pack.rs:155).
3. Global `instance_index` uniqueness stays in `pack.rs` post-processing (not `optimize_multi`).
4. Empty bins must stay in `Vec<SeedResult>` with their input-order index intact.
5. RNG stream continuity — one orchestrator RNG. **One `next_u64()` per bin slot per round, even for empty bins** (positional determinism; Codex sign-off fix).
6. Single-bin fast path bypasses the round loop entirely — critical for Task 9 parity. No orchestrator RNG / round counter / operator scheduling on this path.
7. Hard errors abort the request; `Ok(None)` is recoverable.
8. No partial commits. Operator transactional discipline + orchestrator single-assignment-at-a-time state.
9. **Never carry `CollisionTracker::restore_but_keep_weights()` across assignment mutations** (Codex sign-off). Each round's `optimize_all_bins` call constructs fresh Separators via `search::optimize`; batch-mode always restarts fresh search state, so this invariant holds by construction.
10. `per_bin_quota` is a **lifetime cap** across rounds; do NOT re-grant per round.
11. `unload_lightest_bin` runs ONCE per operator tick, outside the `(a, b)` pair loop (§3.3).
12. Back-off counts **consecutive no-op operator ticks** — not rounds — for termination (§3.1 TERMINATION_NOOP_TICKS).
