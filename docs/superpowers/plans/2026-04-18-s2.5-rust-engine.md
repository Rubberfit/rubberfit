### Task 15: pack-cli streaming protocol ✅

**Files:**
  - `engine/crates/pack-cli/src/main.rs` (streaming mode added)
  - `engine/crates/pack-cli/README.md` (updated)
  - `engine/crates/pack-cli/tests/streaming_protocol.rs` (new)

Shipped 2026-04-18. Two stdin/stdout modes:

- **Batch (default):** read full stdin as a PackRequest, emit one PackResult line.
- **Streaming (`--stream`):** emit NDJSON — one PackProgress line per monotonic global incumbent, then one PackResult as the last line. Stdin cancel via `{"cancel":true}` lines after the initial request.

Key design decisions:
  - First JSON value on stdin is the PackRequest (via `serde_json::Deserializer::from_reader`); subsequent lines go to the cancel-reader thread.
  - `Arc<Mutex<Stdout>>` shared between callback + final-result writer — atomic line ordering.
  - Cancel thread is detached; process exit reclaims it.
  - Write errors inside the callback are swallowed (broken pipe surfaces via the final write).

Tests (3 new):
  - `batch_mode_emits_single_packresult_line`
  - `streaming_mode_emits_progress_then_packresult`
