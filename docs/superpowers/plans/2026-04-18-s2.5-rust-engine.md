## Phase b — BPP bin assignment + cross-bin swap (S2.5b)

### Task 10: FFD bin assignment

**Files:** `engine/crates/rema-layout/src/infrastructure/search/assignment/ffd.rs`

Context: today `pack.rs` iterates bins in input order with greedy spillover. We replace this with area-decreasing FFD to get better initial assignment.

Steps:
1. Sort items by bbox area desc (configurable: longest-edge desc, aspect-aware).
2. For each item, try bins in order; place in first-fit using warm-start greedy.
3. Items that don't fit anywhere → overflow.
4. Tests: three items + two bins where naive order overflows but FFD doesn't.
5. Commit: `feat(search): FFD bin-assignment heuristic`

### Task 11: Cross-bin swap operators

**Files:** `engine/crates/rema-layout/src/infrastructure/search/assignment/cross_bin_swap.rs`

Steps:
1. `swap_two(a_bin, b_bin)` — try moving one item from A to B and one from B to A. Keep if global density improves.
2. `migrate(a_bin, b_bin)` — try moving N items from A to B, ignoring A's remainder. Used when closing a bin.
3. `unload_lightest_bin` — try to empty the lowest-density bin into others.
4. Tests: handcrafted scenarios with known-optimal swaps.
5. Commit: `feat(search): cross-bin swap operators (swap/migrate/unload)`

### Task 12: Integrate FFD + swap into `search::optimize`

**Files:** `engine/crates/rema-layout/src/infrastructure/search/mod.rs`, `engine/crates/rema-layout/src/application/pack.rs`

Steps:
1. `search::optimize` now owns all bins, not one at a time. Signature changes:
   - `search::optimize_multi(request: &PackRequest, seeds: &[SeedResult], cfg: &OptimizerConfig) -> Result<Vec<SeedResult>>`
2. `pack.rs` calls `optimize_multi` once per request instead of looping per bin.
3. Per-bin budget internal to `search::optimize_multi` — it decides how to split.
4. Swap operators run every K iterations of the GLS outer loop (K tuned empirically, default 50).
5. Update all parity snapshots.
6. Commit: `feat(search): multi-bin coordination with cross-bin swap (S2.5b complete)`
