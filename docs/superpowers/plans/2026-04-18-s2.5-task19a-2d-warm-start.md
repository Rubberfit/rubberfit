## 3. Algorithm (homogeneous grid-packer)

For a single `Part` with `quantity = N` on a bin of `(W, H)` under clearance `c`:

```text
bbox(part.polygon) → (w, h)
w_eff = w + 2c   ;   h_eff = h + 2c      (Task 11 clearance inflation, reused)

# Width gate (same as Task 11 probe):
if w_eff > W: emit all N as overflow; return.

cols = floor(W / w_eff)
rows = floor(H / h_eff)
capacity = cols * rows
placed = min(N, capacity)
overflow = N - placed

# Placement order: row-major (j in 0..rows, i in 0..cols) — gives bottom-left
# stability that downstream GLS + FFD expect.
for k in 0..placed:
    j = k / cols
    i = k % cols
    x = i * w_eff + c        # shifted by clearance so halo sits in cell
    y = j * h_eff + c
    emit SeedPlacement { instance_index: k, x, y, ... }
```

Key invariants:
- **Deterministic**: pure arithmetic, no RNG, no Clipper.
- **Task 11 clearance semantics**: `w_eff = w + 2c` is exactly the same formula the current probe uses. Grid cells of size `w_eff × h_eff` mean no two items' halos overlap — items are correctly separated under conservative clearance.
- **Conservative over-rejection preserved**: if `cols * rows * (w+2c)*(h+2c) > W*H`, we stay within. Never over-packs.

## 4. Dispatcher

```rust
pub fn greedy_bottom_left(bin: &Bin, items: &[Part], clearance: f64)
    -> Result<SeedResult, PackError>
{
    if items.len() == 1 && items[0].quantity > 1 {
        return greedy_2d_grid(bin, &items[0], clearance);
    }
    // Heterogeneous or single-copy: fall back to vertical stacker (existing impl).
    greedy_vertical_stack(bin, items, clearance)
}
```

The fallback remains correct for:
- `single-rect.json` (1 part, quantity=1) — stacker is equivalent for N=1.
- `multi-rect-same-size.json` (1 part, qty=6 — but bin is large enough that either works)
- `trapezoid-mix`, `mixed-rect-circle`, `cone-array` (multi-part fixtures)

Even though `multi-rect-same-size.json` would benefit from grid, we include `quantity > 1` in the dispatch condition to avoid touching the N=1 path where stacker == grid.

Wait — `quantity > 1` condition is wrong; we want grid whenever it's a single Part regardless of quantity. Fix:

```rust
if items.len() == 1 {
    return greedy_2d_grid(bin, &items[0], clearance);
}
```

For quantity=1, grid and stacker produce the same result (1 item at `(clearance, clearance)`).
