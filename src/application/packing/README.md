# packing/

Canonical types and pipeline functions that define the single boundary between UI and the packing engine. Every cut-planner Pack call resolves `IPackingService` from DI and speaks only these types — nothing in `app/` imports from `nesting/` directly.

S2 (Rust engine migration) swaps the concrete implementation of `IPackingService` without touching anything here.

## Files

- **types.ts** -- Canonical type definitions. Exports `Point2D`, `ShapeSpec`, `Part`, `Bin`, `PackRequest`, `Placement`, `BinResult`, `PackResult`, `PackProgress`, and the `PACK_MODE_BUDGETS_MS` constant. All polygons are CCW, normalized to (0,0) min-corner; all linear dimensions are inches.
- **buildPart.ts** -- Pure factory that turns a `ShapeSpec` (or a raw polygon) into a canonical `Part`. Guarantees 4-vertex CCW output for `rect` with min-corner at (0,0); supports `circle` with a configurable `segments` count (default 24, minimum 8) producing a polygonalized disc whose bounding box spans the full diameter anchored at (0,0); supports `trapezoid` (`topWidth`, `bottomWidth`, `height` params) producing a 4-vertex CCW polygon centered horizontally within its bounding box with min-corner at (0,0); supports `sector` (annular: `innerRadius`, `outerRadius`, `arcDegrees`, optional `segments` default 24) producing a CCW polygon traced along the outer arc then back along the inner arc, validating `outerRadius > innerRadius` and `arcDegrees` in `(0, 360)` (full annulus not supported — a single-polygon `Part` cannot express holes); supports `ngon` (regular N-gon: `sides`, `radius`) producing a CCW polygon with exactly N vertices, validating `sides >= 3` and `radius > 0` and anchoring vertex 0 at the top via a `-π/2` phase; passthrough polygons are translated to origin and reversed if needed to enforce CCW in math coords. `shapeSpec` is preserved on the returned `Part` as a UI hint (left `undefined` when the caller supplied a raw `polygon`).
- **buildPackRequest.ts** -- Pure factory that assembles a canonical `PackRequest` from UI inputs. Defaults `mode` to `"balanced"`, defaults `timeBudgetMs` to `PACK_MODE_BUDGETS_MS[mode]` when the caller did not pass an explicit value (explicit `timeBudgetMs` always wins), and orders bins by `priority` descending first, then remnants before fresh within equal priority, preserving original insertion order thereafter. Throws when `bins` or `items` is empty.
