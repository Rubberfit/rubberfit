# tests/packing/

Tests for the canonical packing pipeline (`src/application/packing/`) and the packing service boundary (`src/application/services/packing.service.interface.ts`).

Runs under Vitest once installed (S1 Plan Task 3). Type-level assertions use `expectTypeOf`; runtime assertions use standard `expect`.

## Files

- **types.test.ts** -- `expectTypeOf` assertions verifying the canonical type shapes: `Point2D` numeric, `Part` required fields, `PackRequest.bins`/`items` collections, `Placement.binId`/`polygon`.
- **interface.test.ts** -- Verifies `IPackingService.pack(request, onProgress?)` and `cancel(jobId)` signatures and that `PACKING_TOKENS.IPackingService` is a `Symbol`.
- **legacyService.test.ts** -- Verifies the `LegacyPackingService` skeleton: constructs without error, `cancel()` resolves silently for any jobId (intentional no-op — no throw), `pack()` throws `/bins required/i` on empty bins and `/items required/i` on empty items, and resolves (doesn't throw) on mixed-part input now that Task 14 routes mixed items to the GA solver.
- **legacyHomogeneous.test.ts** -- Verifies that `LegacyPackingService.pack()` routes a single-`Part` (homogeneous) request through `greedyNfpPack`: places six 10x5 rects on a 48x96 bin, returns `placedCount: 6` / `overflowCount: 0`, tags `perBin[0].binId` to the input bin, and assigns every placement to that bin.
- **legacyMixed.test.ts** -- Verifies that `LegacyPackingService.pack()` routes a mixed-item request (2+ `Part` entries) through `NFPSolver` (GA solver): places two 10x5 rects plus two 8x4 rects on a 48x96 bin with `mode: "fast"` and `seed: 42`, returns `placedCount: 4` / `overflowCount: 0`, and asserts the canonical mapping contract — every `Placement.shapeId` is the original input id (`"a"` or `"b"`, no `-N` suffix) and `instanceIndex` is a per-shape counter (each shape yields `[0, 1]`).
- **legacyMultibin.test.ts** -- Verifies that `LegacyPackingService.pack()` spills overflow across multiple bins: 40 copies of a 10x10 rect on two 48x48 bins can't all fit on one, so the overflow loop consumes `b2` after `b1` saturates, and the distinct `binId` set across `result.placements` is greater than 1.
- **di.test.ts** -- Verifies the TSyringe container resolves `PACKING_TOKENS.IPackingService` (bridged through `TOKENS.IPackingService`) to a `LegacyPackingService` instance, that repeated resolves return the same singleton, and that `TOKENS.IPackingService` and `PACKING_TOKENS.IPackingService` reference the same underlying Symbol.
- **buildPackRequest.test.ts** -- Verifies `buildPackRequest` assembles a `PackRequest`: defaults `mode` to `"balanced"` and `timeBudgetMs` to `PACK_MODE_BUDGETS_MS[mode]`, honors explicit `timeBudgetMs` as an override of the mode preset, orders bins by priority descending then remnants before fresh within equal priority, and throws `/bins/i` or `/items/i` when the respective collection is empty.
- **buildPlacementView.test.ts** -- Verifies `buildPlacementView(result, request)` (9 cases) joins `PackResult.placements` to their source parts via `request.items` by `shapeId` (resolving `renderShape` via `shapeSpec.kind`), carries `shapeSpec` onto view items for UI rendering, preserves the placed polygon verbatim (value equality, not identity), groups items into `bins[binId]`, carries `perBin` metrics (`efficiency`, `usedArea`) through to the `PlacementViewBin`, carries bin dimensions (`width`, `height`) from `request.bins` onto each `PlacementViewBin`, routes placements to the correct bin under a multi-bin `PackResult`/`PackRequest`, does not throw when a placement has no matching part in `request.items` (leaves `shapeSpec` undefined and falls back to `renderShape: "polygon"`), and falls back to `renderShape: "polygon"` for `dxf`/`svg`/`custom` shape kinds.
- **buildPart.test.ts** -- Verifies `buildPart` for the `rect` shape kind (4-vertex CCW polygon with min-corner at (0,0), `shapeSpec` preserved as UI hint, `/width must be positive/i` on zero width), for the `circle` shape kind (24-vertex polygon by default, bounding box spanning the diameter anchored at (0,0), honors a custom `segments` parameter, throws `/diameter must be positive/i` on zero diameter), for the `trapezoid` shape kind (4-vertex CCW polygon with min-corner at (0,0) and bounding box spanning `max(topWidth, bottomWidth) x height`, throws `/height must be positive/i` on zero height), for the `sector` shape kind (annular polygon with more than 8 vertices and min-corner at (0,0) after normalization across the outer+inner arcs, exactly `2*(segments+1) = 50` vertices at the default 24 segments, bounding-box max ≈ `outerRadius` on both axes for a 90° sector with `outerRadius=5`, throws `/outerRadius must exceed innerRadius/i` when `outerRadius <= innerRadius`, throws `/arcDegrees/i` when `arcDegrees === 360` because a full annulus cannot be expressed as a single-polygon `Part`), for the `ngon` shape kind (regular polygon with exactly N sides, throws `/sides must be at least 3/i` for `sides < 3`, vertex 0 anchors at the top with `y=0` after normalization via the `-π/2` phase, and its x sits on the bounding-box horizontal center), and for the custom / DXF passthrough branch (raw `polygon` input accepted directly with `shapeSpec` left undefined on the returned `Part`, offset polygons translated to min-corner (0,0), throws `/at least 3 vertices/i` when the input has fewer than 3 vertices, throws `/shapeSpec or polygon/i` when neither `shapeSpec` nor `polygon` is provided).

## Subdirectories

### `parity/` — Golden-file snapshot tests

Locks in the observable behavior of `LegacyPackingService.pack()` against a curated set of `PackRequest` fixtures. Each `fixtures/*.json` is a serialized `PackRequest`; the `parity.test.ts` runner iterates every `.json` in `fixtures/`, runs `LegacyPackingService.pack()`, and compares a stable subset of the result (`placedCount`, `overflowCount`, and `perBin[].efficiency` rounded to 4 decimals) to a Vitest snapshot stored in `parity/__snapshots__/parity.test.ts.snap`.

Current fixtures (9 total): `single-rect.json` (baseline), `multi-rect-same-size.json`, `rect-grid.json`, `circle-grid.json`, `cone-array.json`, `trapezoid-mix.json`, `mixed-rect-circle.json`, `multi-sheet-remnant.json`, and `overflow.json`. Together they exercise homogeneous vs. mixed-item routing, rotation on/off, curved polygons (circles + annular sectors), trapezoid non-rectangular geometry, multi-bin spill (remnant-then-fresh), and the overflow path. The plan-listed `zero-items-error.json` is intentionally omitted — the runner does not support expect-error fixtures, and the error path is already covered by `legacyService.test.ts`.

Purpose: detect behavioral regressions during the S1 pipeline refactor before they reach the UI. The S2 canonical solver (when it lands) must reproduce the same snapshots byte-for-byte unless an intentional engine change is documented.

See `tests/packing/parity/README.md` for the full fixture index, fixture authoring guidelines, and the snapshot-regeneration workflow.
