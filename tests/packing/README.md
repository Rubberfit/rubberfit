# tests/packing/

Tests for the canonical packing pipeline (`src/application/packing/`) and the packing service boundary (`src/application/services/packing.service.interface.ts`).

Runs under Vitest once installed (S1 Plan Task 3). Type-level assertions use `expectTypeOf`; runtime assertions use standard `expect`.

## Files

- **types.test.ts** -- `expectTypeOf` assertions verifying the canonical type shapes: `Point2D` numeric, `Part` required fields, `PackRequest.bins`/`items` collections, `Placement.binId`/`polygon`.
- **interface.test.ts** -- Verifies `IPackingService.pack(request, onProgress?)` and `cancel(jobId)` signatures and that `PACKING_TOKENS.IPackingService` is a `Symbol`.
- **legacyService.test.ts** -- Verifies the `LegacyPackingService` skeleton: constructs without error, and `pack()`/`cancel()` both reject with "not implemented" until Phase 3 wiring lands.
- **di.test.ts** -- Verifies the TSyringe container resolves `PACKING_TOKENS.IPackingService` (bridged through `TOKENS.IPackingService`) to a `LegacyPackingService` instance, that repeated resolves return the same singleton, and that `TOKENS.IPackingService` and `PACKING_TOKENS.IPackingService` reference the same underlying Symbol.
- **buildPart.test.ts** -- Verifies `buildPart` for the `rect` shape kind (4-vertex CCW polygon with min-corner at (0,0), `shapeSpec` preserved as UI hint, `/width must be positive/i` on zero width), for the `circle` shape kind (24-vertex polygon by default, bounding box spanning the diameter anchored at (0,0), honors a custom `segments` parameter, throws `/diameter must be positive/i` on zero diameter), for the `trapezoid` shape kind (4-vertex CCW polygon with min-corner at (0,0) and bounding box spanning `max(topWidth, bottomWidth) x height`, throws `/height must be positive/i` on zero height), for the `sector` shape kind (annular polygon with more than 8 vertices and min-corner at (0,0) after normalization across the outer+inner arcs, exactly `2*(segments+1) = 50` vertices at the default 24 segments, bounding-box max ≈ `outerRadius` on both axes for a 90° sector with `outerRadius=5`, throws `/outerRadius must exceed innerRadius/i` when `outerRadius <= innerRadius`, throws `/arcDegrees/i` when `arcDegrees === 360` because a full annulus cannot be expressed as a single-polygon `Part`), for the `ngon` shape kind (regular polygon with exactly N sides, throws `/sides must be at least 3/i` for `sides < 3`, vertex 0 anchors at the top with `y=0` after normalization via the `-π/2` phase, and its x sits on the bounding-box horizontal center), and for the custom / DXF passthrough branch (raw `polygon` input accepted directly with `shapeSpec` left undefined on the returned `Part`, offset polygons translated to min-corner (0,0), throws `/at least 3 vertices/i` when the input has fewer than 3 vertices, throws `/shapeSpec or polygon/i` when neither `shapeSpec` nor `polygon` is provided).
